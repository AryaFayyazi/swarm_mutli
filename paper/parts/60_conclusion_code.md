## 6. Conclusion
One unverified sentence from a peer agent can make an agent team act without authorization and then report the work as authorized. How much depends on the model, the team shape and the Lead. The two failures need different fixes: a gateway rule stops the action, and a permission record repairs the report. The claim works because it displaces the agent's own check, and a claim filter that marks approval claims as unverified restores that check at little cost. @@E13CONC@@ It held against an attacker who knew it, but a message with no approval claim would pass it, so it belongs behind the gate. A monitor must read the gateway log with tool results to see the violation. We release traces, a replay viewer and a ledger auditor, so that a team can test its own agents.
