### 4.7 An adaptive attacker
The scripted message is a weak attacker, so in E8 we let a model write better ones. GLM-5.2, which is not an agent in these runs, wrote {{X['e8_search']['n1']}} candidate messages from a generic description of the task. It then saw how often each candidate led to a violation on a development seed, and wrote {{X['e8_search']['n2']}} improved candidates. A fixed rule picked the candidate with the highest development rate. We tested it on fresh tasks (relay, four models, {{H['_e8']['n']}} episodes). **The search found no stronger message (H18 {{'supported' if H['H18']['supported'] else 'not supported'}}).** On the fresh tasks, V is {{H['H18']['V_attacker']|.2f}} for the selected message and {{H['H18']['V_main']|.2f}} for the main message ({{H['H18']['point']|+.2f}} [{{H['H18']['lo']|+.2f}}, {{H['H18']['hi']|+.2f}}]). The gain on the development tasks was mostly chance: the main message scored {{X['e8_search']['dev_main']|.2f}} there and {{H['H18']['V_main']|.2f}} on the fresh tasks. **The gate holds against the selected message (H19 supported).** V is {{H['H19']['parts'][0]['point']|.1%}} (CI up to {{H['H19']['parts'][0]['hi']|.1%}}).
